# Teacher review pack

Status: DRAFT for review (H-07). All numbers in the sample come from fictional demonstration data.

## 1. Sample report

Open `docs/review/sample-educator.html` in a browser and print it to PDF (A4 portrait). It shows the School (educator) report for the fictional learner "Demo Learner" (P-07), last 7 days, labelled "Sample data". A real PDF export from the tablet is a device step (`NOT RUN`).

## 2. Definitions used

| Measure | Definition | Source | Minimum data |
| --- | --- | --- | --- |
| `class_messages` | `messages_sent` restricted to sessions with setting `school` | auto/adult | none |
| `class_help_requests` | Meaningful uses of `sym_help` plus uses of `phr_help` in school sessions | auto/adult | none |
| `class_independent_starts` | `independent_starts` restricted to school sessions | adult | 5 school sessions in period |
| `class_words` | `top_words` restricted to school sessions | auto/adult | none |
| `class_prompted_vs_independent` | `prompted_vs_independent` restricted to school sessions | adult | 5 school sessions in period |
| `class_messages_weekly` | Messages in school sessions per week for the 6 weeks ending at period end | auto/adult | none |
| `goals` | Active goals visible to the role, with the latest progress entry inside the period | adult | when a goal exists |

Rates, comparisons and planning ideas need at least 5 sessions in the period (D-15). Counts and lists show from the first session.

## 3. Planning idea texts

- PI-E1 (class help requests of 1 or more): "{helpWord} was used for {n} help requests in class. Consider preparing symbols for the next class activity."
- PI-E2 (class messages of 1 or more): "{n} messages were recorded in class. Consider planning one more chance to choose during each lesson."
- Every idea ends: "A suggestion for adults. Nothing in the app changes by itself."

## 4. Limitation notice shown on every report

> This report describes recorded app activity, not all communication. Usage statistics alone do not show language development.
